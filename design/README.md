# Island Rush — design records

Current game: https://island-rush-six.vercel.app. Current behavior is documented
in [the game guide](../devpost/game-guide.md), [PRD](../devpost/prd.md), and
[spec](../devpost/spec.md). The records below preserve the actual design process;
old prompts and screenshots are not claims of current functionality.

- [Current production screenshots](devpost/production-captures.md): real deployed
  island and coastal runner, captured 24 October and uploaded to Devpost.
- [Coastal experience v3](coastal-experience-v3.md): active coastal jungle art,
  distant island, clear foliage bounds, softer projection, eight-block placement,
  endless pace, direct map moves, and original generation prompts.
- [Township terrain v2](township-island-v2.md): active connected-road island asset
  and its source/prompt. Later placement changes are in the current guide.
- [UI/UX revision v2](ui-ux-revision-v2.md): earlier intermediate design record,
  superseded by township/coastal/placement/endless follow-ups.
- [Original runtime art prompts](runtime-art-prompts.md): provenance for the
  original character/buildings/pickups and older island/route assets. Archived
  world images remain in the asset manifest; they are not all loaded at runtime.
- [Promotional thumbnail](devpost/thumbnail-provenance.md): generated artwork,
  separate from the actual screenshot gallery.
- `reference/`: early concept studies, not playable-game captures.
- `checkpoints/`: historical first-playable screenshots, not the current build.

No original generation prompt is rewritten to pretend it requested a later
revision. New source records identify what changed and when.
