## First comparison board

Output: island-rush-visual-study-v1.png.

Use case: ui-mockup
Asset type: one landscape art-direction comparison board for an original small browser game, presented as an exploratory visual study.
Primary request: Help an experienced developer learn to imagine a coherent, attractive game visual identity and UI. Create a polished single comparison board for the working concept Island Rush: short runner rounds collect timber, then the player uses it to grow a tiny island. These are three equally viable suggestions, not a selected design. The learner likes City Island, Subway Surfers and Temple Run; do not copy any existing game's characters, assets or branding.

Composition: landscape 3:2 board, three equal columns with generous spacing on a warm neutral editorial background. Each column has a short style heading, a large landscape gameplay concept frame above, and a smaller landscape island-building frame below. All six frames are complete visible screens, no phone hardware mockups and no cropping. Give all three columns the same scene, camera geometry and UI organization so differences in art direction are easy to compare. The game art is the main content; labels are sparse and highly legible.

Common gameplay scene in each upper frame: an original small courier seen from behind, running away from camera along a clearly readable three-lane coastal wooden causeway toward a little island settlement. Show the courier in the lower third, several collectible timber bundles, one obvious rounded barrier in one lane, clear distance between pickups and the obstacle, and a clean horizon. Sunny tropical island setting. Keep the gameplay path visually dominant and avoid busy scenery behind obstacles. Minimal HUD: a compact timber counter reading "12 / 30" at top left and a small pause button at top right. No sidebars, dashboards, cards full of statistics, navigation menus or oversized overlays. Preserve space around the courier.

Common island scene in each lower frame: a compact island surrounded by water, one completed tiny cottage, one visibly unfinished workshop foundation, and one additional empty building plot. A small build callout next to the foundation reads "30 WOOD", and one clearly visible main action reads "BUILD". Make the architecture and interface match the corresponding runner art. The island view should visibly communicate what the run's collected materials are for.

Column A: heading exactly "A  TOY ISLAND". Art direction is a premium stylized 3D toy diorama with rounded chunky silhouettes, matte handcrafted surfaces, warm sunlight, soft contact shadows, turquoise water, leafy greens and limited coral accents. UI uses compact cream surfaces and rounded readable type.
Column B: heading exactly "B  PAINTED ADVENTURE". Art direction is a rich hand-painted 2.5D coastal storybook with expressive brush textures, warm gold and deep sea blue, strong silhouettes and atmospheric depth. Artful but readable. UI uses restrained parchment-colored accents and tidy humanist type, never distressed unreadable lettering.
Column C: heading exactly "C  PIXEL COAST". Art direction is sophisticated crisp pixel art with a deliberate limited tropical palette, carefully stepped highlights, charming small architecture, legible pixel typography and strong scene layering. Keep this column authentically pixel art, not blurry digital painting. The exact same gameplay layout remains readable.

Board title exactly "ISLAND RUSH"
Board subtitle exactly "Three possible visual directions"
Small footer exactly "Concept study"
Constraints: This is one cohesive comparison-board image, not separate requested assets. Prioritize beautiful original game scenes, strong player/obstacle/collectible separation, coherent UI within each art direction, and readable typography. Do not add explanation paragraphs, fake metrics, logos, watermarks or any text beyond the specified headings, subtitle, counters, action labels and footer. No direction should be presented as the winner.
